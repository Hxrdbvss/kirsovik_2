# Демонстрационный академический набор

Версия: academy-demo-v1. Все студенты, преподаватели, учебные планы и результаты вымышлены и созданы специально для этого проекта. Это синтетические данные для проверки приложения; они не получены из OULAD и не использовались для обучения модели риска.

В наборе две группы второго курса: ПИ-21 «Программная инженерия» и ИВТ-21 «Информатика и вычислительная техника». В каждой группе 15 студентов и восемь дисциплин третьего семестра. Всего десять разных дисциплин, 22 развёрнутых вводных учебных материала и 110 вопросов — по пять на тему. У каждой группы 18 тем; полное прохождение её плана даёт 540 баллов.

Общие дисциплины: машинное обучение, Python, базы данных, веб-технологии, алгоритмы, теория вероятностей и статистика. ПИ-21 дополнительно изучает программную инженерию и информационную безопасность, ИВТ-21 — компьютерные сети и операционные системы.

| Файл | Содержимое |
| --- | --- |
| academy.json | Полный импорт: группы, планы, дисциплины, студенты и попытки с выбранными ответами |
| students.csv | 30 студентов: id, full_name, group_id, active, source, scenario |
| disciplines.csv | 10 дисциплин: id, name, description, teacher, semester |
| group_disciplines.csv | 16 связей группы с дисциплиной |
| activities.csv | Результаты попыток: student_id, material_id, score, created_at |
| additional_materials.json | 18 материалов девяти новых дисциплин; исходные четыре темы машинного обучения сохранены отдельно |
| additional_quizzes.json | 90 новых вопросов с ключами и объяснениями; файл используется сервером |

CSV записаны в UTF-8 с BOM и разделителем «;», подходят для открытия в Excel. Время попыток — UTC. Идентификаторы связывают файлы, названия не используются как ключи. Поле scenario обозначает заданный сценарий демонстрации, а не диагноз или результат модели: advanced, steady, practice, support, new. Имеются как успешные попытки, так и ошибки, повторные прохождения и профили без активности.

Воспроизведение из корня проекта:

```text
python datasets/build_academy_demo.py
```

Генератор использует фиксированное зерно 20261109. Импорт выполняет academy_core.ensure_academy: создаёт таблицы без удаления прежних, сохраняет маркер версии и загружает данные один раз в транзакции. Результаты вычисляются по ответам, награда выдаётся по обычному правилу. Повторный запуск сайта не восстанавливает отредактированные имена и не дублирует попытки. Повторная генерация файлов сама по себе не изменяет уже загруженную SQLite; для отдельной чистой проверки задайте LEARNING_PROGRESS_DB и перезапустите API.

Редактируемые развёрнутые конспекты находятся в learning-content. Это вводный набор занятий, а не полный комплект материалов восьми семестровых курсов. Ключи ответов входят в исходники для воспроизводимости; данный режим предназначен для самопроверки.
