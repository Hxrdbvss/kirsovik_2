### 1. Три слоя страницы

**HTML** описывает структуру и смысл документа: заголовки, абзацы, ссылки, формы. **CSS** задаёт оформление и расположение. **JavaScript** позволяет обрабатывать действия пользователя и менять состояние страницы. Простая форма может работать с отправкой на сервер и без собственного JavaScript.

Разделение ответственности облегчает изменения. Если требуется другой цвет кнопки, обычно меняют стиль; если нужна проверка права пользователя — серверную логику. Скрытая через CSS кнопка не означает, что операция запрещена на сервере.

### 2. Разобранный пример HTML

```html
<main>
  <h1>Учебный кабинет</h1>
  <p>Выберите группу для просмотра плана.</p>
  <form action="/groups" method="get">
    <label for="group">Учебная группа</label>
    <select id="group" name="group">
      <option value="pi_21">ПИ-21</option>
      <option value="ivt_21">ИВТ-21</option>
    </select>
    <button type="submit">Открыть план</button>
  </form>
</main>
```

Заголовок сообщает назначение страницы. Label связан с полем по id, а name задаёт имя передаваемого значения. Если выбрана ПИ-21, форма с методом GET направит значение `group=pi_21` на указанный адрес. Наличие HTML-формы не создаёт обработчик `/groups`: он должен существовать отдельно.

### 3. Оформление и адаптация

```css
main { max-width: 60rem; margin: 0 auto; padding: 1rem; }
button { padding: 0.7rem 1rem; border-radius: 0.6rem; }
@media (max-width: 40rem) {
  button { width: 100%; }
}
```

Правило max-width ограничивает ширину текста, а медиазапрос растягивает кнопку на узком экране. В реальной странице также задают viewport и проверяют длинные подписи, таблицы и увеличение масштаба. Адаптивность интерфейса по ширине отличается от педагогической адаптации по результату теста.

### 4. Смысловая структура и доступность

Заголовки должны образовывать понятную последовательность. Подпись поля помогает человеку и вспомогательным технологиям понять ожидаемый ввод. Кнопку следует использовать для действия, ссылку — для перехода. Цвет полезен как дополнительный сигнал, но результат лучше объяснять и текстом: «Тема освоена», «Нужна практика».

JavaScript может обновить число результатов после фильтрации или раскрыть блок. Серверная проверка входных значений всё равно необходима: клиентскую проверку можно обойти. В нашем приложении многие элементы создаёт Streamlit, поэтому HTML-пример объясняет основы, а не заменяет его точку запуска.

### 5. Типичные ошибки

- Смешивать семантический смысл заголовка с желаемым размером шрифта.
- Оставлять поле без понятной подписи.
- Делать весь макет шириной в фиксированное большое число пикселей.
- Считать скрытый элемент достаточным контролем доступа.

### 6. Что запомнить

HTML задаёт содержание, CSS — внешний вид, JavaScript — дополнительное поведение. Форма собирает значения и отправляет их обработчику. Удобство проверяют на разной ширине экрана и с клавиатуры, а данные — на сервере.
