# Учебная библиотека

Здесь находятся 22 вводных занятия по десяти дисциплинам. Каждой теме соответствует Markdown-файл с устойчивым id: mat_01–mat_04 относятся к машинному обучению, остальные используют идентификатор дисциплины и номер темы.

Материалы включают теорию, разобранные примеры, типичные ошибки и итоговые понятия. В catalog.json находятся краткое описание, учебные ориентиры, самостоятельное задание, ориентир для проверки и ссылки на документацию. Тексты написаны для проекта, внешние страницы используются для проверки понятий и дополнительного чтения; содержание не является полной программой семестровой дисциплины.

Редактирование:

1. Измените соответствующий .md. Сохраните id и учебные понятия, которые проверяет существующий тест.
2. При необходимости обновите assignment, self_check, outcomes и sources в catalog.json.
3. Из корня проекта выполните `python datasets/build_lessons.py`.
4. Обновите страницу сайта. Если изменялся Python-код, перезапустите API и интерфейс.

Сборщик обновляет material_content.json, additional_materials.json и тексты практики в двух файлах вопросов. Сами вопросы, варианты, ключи и идентификаторы не меняются. Дополнительно создаётся общий файл docs/Учебные_материалы.md. База прогресса при сборке не открывается и не изменяется.

Генератор datasets/build_academy_demo.py после генерации синтетических каталогов повторно вызывает сборщик занятий, поэтому не заменяет их краткими заготовками. Изменения уже импортированной истории из-за этого не происходят.

В интерфейсе доступны свёрнутые блоки самостоятельной работы, ориентира и источников, а также загрузка конспекта текущей темы. Ориентир предназначен для самостоятельной проверки: задания не отправляются на сервер и не дают отдельной награды. Для освоения используется тест из пяти вопросов.

quiz_fingerprints.json содержит контрольные суммы исходных вопросов для проверки совместимости результатов. Редактирование конспектов не требует их изменения. Если вы намеренно меняете сами вопросы, обновление контрольных сумм и судьба старых попыток должны быть отдельным согласованным изменением.
